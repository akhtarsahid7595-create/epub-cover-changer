# Premium typography

Use this skill when improving a product UI where text feels misaligned, generic, crowded, or visually cheap.

- Establish a clear type scale before changing individual text sizes.
- Use one primary sans family, one restrained editorial accent, and monospace only for metadata or technical labels.
- Keep headings short, high-contrast, and aligned to the section’s visual axis.
- Limit readable body text to a comfortable measure; never stretch paragraphs across the whole viewport.
- Treat eyebrow, title, description, CTA, metadata, and helper text as separate hierarchy levels.
- Align text blocks, buttons, and supporting labels to a shared container grid.
- Use whitespace to group related content and separate unrelated sections.
- Use color to reinforce hierarchy: strongest color for headings/actions, muted color for support copy, accent color sparingly.
- Prefer subtle transitions for state changes; avoid decorative motion that competes with reading.
- Always check desktop and narrow mobile layouts for wrapping, overflow, and tap-target clarity.

For redesigns, preserve existing functionality and use real copy that accurately describes the product. Do not add invented testimonials, metrics, or unsupported claims.
